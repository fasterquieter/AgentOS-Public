# Current AgentOS state

Updated: 2026-09-18

## Working

- Markdown is canonical project memory. The optional zero-dependency CLI now
  supports conservative initialization, read-only seed-adaptation previews,
  omission-safe context discovery, observed-failure routing evaluations,
  validation, and record creation.
- The packaged starter creates only five project knowledge documents plus thin vendor adapters and verified bootstrap observations.
- Framework guides, specialist perspectives, optional templates, CI, and the customized TrailCache example are complete for the first alpha.
- The repository uses its own AgentOS catalog, accepted decisions, and continuity simulations.
- The complete repository is now a self-identifying project seed: an ordinary
  product prompt triggers agent-led adaptation; a deterministic transaction
  report exposes replacements, removals, preservation, and changed targets
  before semantic work begins.
- Optional change-control policy, workstream/integration reconciliation, and one
  real routing-noise regression now cover the first governance, parallel-work,
  and routing-evaluation stories without adding a service or scheduler.
- AgentOS now includes an optional, dormant behavior proof-map capability. It
  links consequential behaviors and routes/states to falsifiable oracles and
  capability, route, environment, and human evidence without becoming product
  authority or mandatory seed memory.
- The full 32-test suite, strict validation, TrailCache routing corpus,
  tiny/complex adaptation, later activation, fresh handoff, and deliberate
  failure checks pass as of 2026-09-18.

## Incomplete

- Semantic truth still requires agent/human evidence; deterministic validation checks structure only.
- Instruction following remains probabilistic; the lifecycle harness proves the
  written transformation is coherent, not that every future vendor model will
  interpret every ambiguous prompt identically.
- The preview makes file operations inspectable but deliberately does not infer
  project meaning or apply the semantic transition.
- Change control records intent but does not enforce hosting permissions. The
  parallel reconciliation protocol has not yet been exercised by a real team.
- Adapter drift validation is a proposed improvement, not yet accepted.
- The routing corpus contains one observed failure. Real installations are still
  needed to measure more misses, upkeep, and warning fatigue before considering
  semantic retrieval.
- Proof-map activation thresholds have repository-history and synthetic lifecycle
  evidence but still need observation across several real projects. No shared
  structured schema has earned its maintenance cost.

## Next

   and compare its applied transition with the generated preview.
2. Exercise two genuinely parallel workstreams and record where the integration

4. Pilot small Markdown proof maps in real projects and measure whether they
   prevent route/oracle overclaims without becoming ceremonial documentation.
5. Pilot an agent-led migration in an existing mature repository without copying
   or destroying its canonical docs; the clone seed is for new repositories, not
   a forced mature-repository migration.
