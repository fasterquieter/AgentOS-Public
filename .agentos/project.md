# AgentOS project definition

Verified: 2026-08-26 against the repository and founding brief.

## Purpose

AgentOS is project memory for coding agents. It gives a capable new coding agent
durable, Markdown-first knowledge and a concise route to the useful slice of
intent, state, constraints, and evidence without inheriting a previous chat or
loading a documentation warehouse.

## Users

- Humans directing AI coding agents across sessions, models, and vendors.
- Coding agents resuming, reviewing, testing, or maintaining a repository.
- Framework maintainers learning across multiple AgentOS-enabled projects.

## Product boundary

AgentOS owns repository-local Markdown memory, a clone-as-seed adaptation
protocol with a deterministic transaction preview, dormant capability guidance,
routing metadata and observed-failure evaluations, knowledge change control,
parallel-work reconciliation guidance, maintenance conventions, reusable review
perspectives, optional behavior-to-evidence accounting, and optional
deterministic hygiene/discovery tooling. Tools advise and check mechanics; agents
decide project identity from task intent, semantic relevance, migration
authority, interpretation, and review scope. AgentOS does not run coding agents,
replace source control, enforce repository permissions, prove undocumented
behavior, or require a hosted service/vector database.

## Success

A human can clone the complete repository, provide only an ordinary project prompt, and rely on the first agent to create a project-native active memory while preserving dormant capability. Later agents can answer what they are doing, why, what remains, what to read, and what not to break from a focused selection materially smaller than the on-disk library. The workflow remains understandable without the optional CLI.

## Non-goals

- A fictional organization of autonomous personalities.
- Automatic truth extraction from arbitrary code.
- Mandatory creation of every optional knowledge type.
- A universal agent orchestration runtime.
- Requiring humans to install or operate AgentOS before starting a cloned project.
